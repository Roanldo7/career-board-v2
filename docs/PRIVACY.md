# 数据与隐私说明

本说明对应 2026-10-22 公开前检查的 V2 2.0.0 源码快照与 Release EXE。

## 仓库中包含什么

- 应用源码、依赖锁、字段／结构定义及第三方许可说明。
- 以“合成企业”“合成岗位”等名称构造的单元测试数据。
- 已查看确认的隔离数据截图。
- 使用虚构企业和 example.com 链接的 CSV 导入示例。

仓库中的 `package.json`、`package-lock.json`、`tsconfig.json`、`schema.json` 和 `xlsx_columns.json` 是程序或开发配置，**不是作者的个人岗位或投递数据库**。

## 没有包含什么

没有上传作者本人的岗位列表、投递记录、个人业务 JSON、完整备份、简历、求职研究表格、正式运行 profile、浏览器会话或机器专用运行时配置。没有继承原工作区的 Git 历史。

首次使用成品为空库；个人数据在使用软件后保存在各自电脑的 `%APPDATA%\CareerBoardV2`，不是从 Release 附件中加载作者的资料。下载程序不会自动获得 README 截图中的合成记录。

## 本次做了哪些检查

1. 检查独立仓库的全部跟踪文件和本次新增资料，确认 JSON 文件的用途及实际上传范围。
2. 静态查看 EXE 外层文件目录，并解出内部 `resources/app.asar`；没有启动 EXE 或改写正式数据库。
3. 内部应用包仅有 7 个文件：第三方说明、编译后的主进程／预加载／前端文件、HTML、CSS 与应用元数据。未发现岗位数据库、投递数据、备份或种子业务 JSON。
4. 核对打包代码首次初始化的岗位和申请为空数组，存储构造没有传入个人种子数据。
5. 在本机内存中只读比对真实业务数据的较长记录标识与备注，未命中；该比对资料没有写入仓库。另检查常见密钥格式及作者姓名／本机用户名，未发现命中。
6. 查看所选截图，确认可见企业、岗位与备注为合成内容；示例 CSV 也由虚构数据生成。
